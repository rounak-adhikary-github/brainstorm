# 2026-09-18

## Rebuilt the "Pin the trip on the map" section (index.html)

**Problem:** The map basemap used CARTO `basemaps.cartocdn.com/dark_all` tiles. CARTO now
requires an API key, so every tile was stamped with a huge "API KEY REQUIRED /
carto.com/basemaps/apikey" watermark and the style rendered near-black with white labels —
i.e. "black and white maps with lots of watermarks".

**Fix / changes in `index.html`:**
- Removed the CARTO tile layer entirely. New key-free, watermark-free provider chain:
  - `sat` → Esri `World_Imagery` + `Reference/World_Boundaries_and_Places` (hybrid labels)
  - `street` → Esri `World_Street_Map`
  - `dark` → Esri `Canvas/World_Dark_Gray_Base` + `Canvas/World_Dark_Gray_Reference`
  - fallback for every layer → `tile.openstreetmap.org`
  All are `server.arcgisonline.com/ArcGIS/rest/services/.../MapServer/tile/{z}/{y}/{x}`
  (note the Esri `{z}/{y}/{x}` order, not `{z}/{x}/{y}`).
- Added a `BASE_LAYERS` map + `setBaseLayer(key)` with a per-layer provider walk-down on
  `tileerror`, and a base-layer switcher UI (`.maptools` / `.mbtn`) in the map stage.
- Added a `.mapzoom` segmented +/− control and a `#mapFit` button; Leaflet's default
  `zoomControl` is now off so nothing collides with the switcher.
- Category-coloured markers: `CAT_COLOR` / `catColor()` drive new `.mpin` teardrop pins,
  the category chips, the map list badges and the schematic pins.
- Hover tooltips on pins; popup open/close toggles an `.mpin.on` pulse halo.
- Pinned the badge text per layer; "Open in Google Maps" got a solid dark backing so it
  stays readable over the pale street tiles.
- Mobile (<=900px): control labels collapse to icons via `.mlabel` / `.hide-sm`.

**Gotcha worth remembering:** Leaflet panes (`.leaflet-map-pane` and every child pane) have
**zero intrinsic size**, so an overlay div with `inset:0` inside a pane renders at 0x0 and is
invisible. To tint a basemap, apply a colourising CSS `filter` to `.leaflet-tile-pane`
instead — e.g. midnight uses `sepia(.9) saturate(3) hue-rotate(178deg) brightness(.86)
contrast(1.14)`.

**Verification method:** no Playwright/agent-browser installed, but Edge is present. Drove
headless Edge over CDP (`--remote-debugging-port`, `Page.captureScreenshot`) from a small
node script. Note: plain `msedge --headless --screenshot` produces a blank frame for this
page (scroll/render not applied) — CDP works.
